# Efeitos sonoros do Blocky

Adicione os arquivos de efeitos neste diretório usando exatamente estes nomes:

- `block_placed.wav` — posicionamento válido normal.
- `block_cut.wav` — pedaço excedente cortado.
- `perfect.wav` — posicionamento Perfect.
- `perfect_recovery.wav` — ativação de Perfect Recovery.
- `game_over.wav` — fim de partida.

Arquivos `.wav` curtos são recomendados para esta primeira versão. O diretório
já está declarado como asset no `pubspec.yaml`; não é necessário alterar código
ao adicionar os efeitos.
