# Efeitos sonoros do Blocky

Este diretório já contém efeitos sonoros originais e curtos para a primeira
versão do jogo:

- `block_placed.wav` — posicionamento válido normal.
- `block_cut.wav` — pedaço excedente cortado.
- `perfect.wav` — posicionamento Perfect.
- `perfect_recovery.wav` — ativação de Perfect Recovery.
- `game_over.wav` — fim de partida.

Os arquivos são `.wav` mono, 44.1 kHz, e o diretório já está declarado como
asset no `pubspec.yaml`; não é necessário alterar código ou rodar `pub get`.
